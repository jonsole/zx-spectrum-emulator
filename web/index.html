Knight Lore on the Filmation engine

A ZX Spectrum emulator, this project's C++ core compiled to WebAssembly, running the Filmation remake of Ultimate's Knight Lore.

Playing

At the menu, 1–4 choose the controls and 0 starts. Keyboard (1) is the one to pick: Kempston isn't emulated here.

TurnZ C B M one way, X V N Ctrl the other
Walkany of A–L, or Enter
Jumpany of Q–P
Pick up / dropany number

For cursor control (3), the arrow keys are the Spectrum's 5–8 and Space is fire (0). Shift is CAPS SHIFT; Ctrl and Alt are SYMBOL SHIFT.

Where the game comes from

The game isn't hosted here. Its graphics and font are Ultimate's, so building it takes your own copy of the original. With that, examples/filmation/extract.py and knightlore/build.py write knightlore/output/knightlore.z80, the file to open here. The Filmation README has the steps.

The last snapshot you opened is kept in this browser, so it's back the next time you visit. Any other 48K or 128K .z80 or .sna runs as well.
