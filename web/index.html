ZX Spectrum in the browser

This project's C++ emulator core compiled to WebAssembly. Open a 48K or 128K snapshot and it runs.

The keyboard

Letters, numbers, Enter and Space are the Spectrum's own keys.

CAPS SHIFTShift
SYMBOL SHIFTCtrl or Alt
DELETEBackspace
5 6 7 8← ↓ ↑ →, unshifted, as a cursor joystick reads them

There is no Kempston joystick: in a game's menu, pick the keyboard or cursor keys.

Snapshots

Opens .z80 (versions 1 to 3) and .sna, 48K or 128K; the machine switches to whichever the snapshot was taken on. Nothing is uploaded: the file is read in this page.

The last snapshot you opened is kept in this browser, so it's back the next time you visit. Reset restarts the machine into its ROM: BASIC, with no snapshot needed.
